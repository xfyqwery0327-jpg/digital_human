## pip install -r requirements.txt 失败排查（robot env / Python 3.10.20）
- 用户现象：在 `robot` 环境执行 `pip install -r requirements.txt` 报 `numpy==2.5.2 No matching distribution found`。
- 根因：`requirements.txt` 是在 **Python 3.14** 环境 freeze 的（文件头部注释亦写「Python 3.14」），与 `robot`(3.10.20) 环境是**两套完全不同的版本栈**。
- Py3.10 上至少 3 个包装不上（逐层 dry-run 验证）：
  - `numpy==2.5.2` → 需 ≥3.12，3.10 最高 2.2.6
  - `onnxruntime-gpu==1.29.0` → 3.10 最高 1.23.2
  - `websockets==17.1` → 需 ≥3.11，3.10 最高 16.1.1
  - 后续 protobuf 7.35.1 等预计同样不行（whack-a-mole）
- robot 环境实际版本（生产在跑，CV2 RTF 1~2 验证 good）：numpy 1.26.4 / onnxruntime-gpu 1.23.2 / protobuf 4.25.0 / websockets 11.0.3 / typer 0.24.2 / pydantic 2.13.4 / click 8.4.2。
- 项目生产环境 = `robot` env：ROBOT_API.md「现场须用 conda env **robot** 启动」；monet/chat.py、build_rag.py、deploy/pack-for-server.ps1 等脚本头部均 `conda activate robot`。
- 结论：不该往 robot 灌这份 3.14 清单（会把 protobuf 4.25→7.35、websockets 11→17、numpy 1.26→2.5 等大跳变塞进生产环境，且 3.10 上根本装不完）。
- robot 环境全程未被我改动（所有安装均为 --dry-run；pip 新版解析器在解析失败时不安装任何包）。
- 曾临时创建 `digital_human` conda 环境（python 3.14.8 + pip，未装 requirements）；用户确认走 3.10 路线后已删除该环境，robot 环境保持原样未动。

## qwen-tts 装入 robot 环境引发的问题（13:19~13:21）
- 用户在 robot 环境装 qwen-tts 0.1.1，拉入 sox / tokenizers 0.21.4→0.22.2 / onnxruntime(CPU) / accelerate / transformers 4.57.3 / gradio 6.17.3。
- 安装时 WinError 5 拒绝访问 onnxruntime_providers_shared.dll：非权限问题，是服务进程占用 DLL（PID 13152@10:24、17748@13:12，各占数百 MB）；停进程后重装成功。
- pip 冲突警告 matcha-tts 0.0.7.2 vs gradio 6.17.3：**无害**——项目代码零处 import gradio/matcha（全库 grep 无匹配），gradio 仅是 matcha-tts/qwen-tts demo 所用。环境原本就有 3 个老冲突（bitsandbytes↔torch 2.3.1、langgraph-sdk/langsmith↔websockets 11），项目一直正常运行，pip check 报红≠不可用。真要消掉可 uninstall matcha-tts。
- **真问题：onnxruntime(CPU) 覆盖了 onnxruntime-gpu 1.23.2 的文件**（两包同装 site-packages/onnxruntime/，互相覆写）。验证：`ort.get_available_providers()` 仅 CPU/Azure，CUDAExecutionProvider 丢失。影响：cosyvoice.py 中 ONNX 会话（speech_tokenizer_v2.onnx/campplus.onnx）迁 CUDA 的代码静默失效，前端退 CPU 跑。修复：`pip install --force-reinstall --no-deps onnxruntime-gpu==1.23.2`（截至记录时待用户确认执行）。
- sentence-transformers 5.7.0 + transformers 4.57.3 + tokenizers 0.22.2 组合正常，RAG（GTE 嵌入）链路不受影响。
